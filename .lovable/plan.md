

# CamScript — Landing Page Implementation

## Overview
Convert the existing CamScript HTML landing page into a polished React application with a macOS-inspired menu bar navbar and rich visual elements throughout.

---

## 1. macOS Menu Bar Navbar (Matching Screenshot Exactly)
- Fixed top navbar styled as a macOS menu bar (dark, translucent, 28px height, blur backdrop)
- **Left side**: Apple logo icon → **"CamScript"** (bold) → Features, Setups, FAQ, Pricing links
- **Right side**: "Download" link, Bluetooth/Wi-Fi/Search/Control Center icons, live date/time display
- Mobile: hamburger menu with dropdown
- Auto-hide on scroll down, reappear on scroll up

## 2. Hero Section
- "Now available for macOS" pill badge with pulsing green dot
- Bold headline: "Meet CamScript — Your discreet notch prompter."
- CTA buttons: "$19 — One-time Purchase" and "Start Free Trial"
- **Interactive MacBook mockup** with realistic bezel, notch with camera, scrolling CamScript prompter text, and a Zoom-like video call UI with participant thumbnails

## 3. Setups Section (Bento Grid)
- Two cards with mini MacBook illustrations:
  - **Notch Prompter**: shows text scrolling inside the notch area
  - **Floating Window**: shows a draggable floating prompter window with animation
- Hover effects on cards (lift + shadow)

## 4. Features Section (Bento Grid)
- 8 feature cards in a responsive bento layout (mix of wide and standard cards)
- Features: Invisible to audience, Right at camera, Floating window, Pause instantly, Control the pace, Fully customizable, Privacy (100% local), Built-in editor
- Wide cards include inline illustrations (screen share demo, lock/privacy graphic)
- Icons for each feature, smooth reveal-on-scroll animations

## 5. FAQ Section
- Accordion-style FAQ with 5 questions
- Smooth expand/collapse animations with rotating chevron icons
- Clean card-style layout

## 6. Pricing Section
- Single pricing card with subtle glow border effect
- Large "$19" price display, "One-time payment" label
- Checklist of benefits with checkmark icons
- CTA button + "Start Free Trial" link
- macOS version requirement note

## 7. Footer
- Minimal footer with CamScript branding, copyright, and links

## 8. Animations & Polish
- Scroll-reveal animations with staggered delays
- Floating animation on elements
- Smooth scrolling between sections
- Scrolling text animation in prompter mockups
- Hover effects on all interactive elements

## Design System
- Clean, Apple-inspired aesthetic with light background
- Inter font family
- Color palette: carbon (#1a1a1a), ash (#2a2a2a), smoke (#6b6b6b), mist (#f5f5f7), pearl (#fafafa)
- Rounded corners, subtle shadows, minimal borders
