# CamScript

Your discreet notch prompter.

## Getting Started

**Prerequisites:** Node.js & npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
git clone git@github.com:RohanGosavi/camscript.git
cd camscript
npm i
npm run dev
```

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
